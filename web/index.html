Como se puntua

puntos = base x tiempo x intentos

Base segun dificultad

NivelNombrePuntos

Factor tiempo

Va de 1.00 cuando se abre la ronda a 0.65 cuando cierra, bajando parejo. Resolver temprano vale mas, pero entregar tarde siempre suma bastante mas que no entregar.

Factor intentos

Cada envio rechazado antes del aceptado descuenta un 15%, con piso en 0.40. Los errores de sintaxis no penalizan, igual que en ICPC. Reenviar nunca te baja el puntaje: se guarda tu mejor resultado.

Desempate

Mas puntos, despues mas problemas resueltos, despues menos tiempo total hasta los aceptados, y por ultimo quien llego primero a ese puntaje.

Como se participa
